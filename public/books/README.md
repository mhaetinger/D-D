# Livros para consulta

Os dois PDFs foram incluídos a pedido do responsável pelo projeto para consulta
dos participantes. Não são cobertos pela licença MIT do código; os créditos e
avisos presentes nos próprios livros continuam aplicáveis.

| Arquivo | Referência | Páginas do PDF |
| --- | --- | --- |
| `livro-jogador-2014.pdf` | Exemplar do Jogador usado nas regras da ficha, incluindo o Patrulheiro Revisado. | 314 |
| `livro-mestre-2014.pdf` | Exemplar do Mestre para consulta; não altera o motor da ficha. | 322 |

`book.html#page=N` mantém os links existentes ao Livro do Jogador.
`book.html#book=mestre&page=N` abre o Livro do Mestre.
A página do PDF é contada a partir de 1 e pode diferir da numeração impressa.
O leitor integrado usa PDF.js local, com navegação, zoom e texto selecionável.
Os links de abertura e download permanecem disponíveis quando o leitor falha.
Nenhuma ficha de personagem foi incluída nesta pasta.

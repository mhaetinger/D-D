# Dependências distribuídas

Os arquivos de licença nesta pasta foram copiados dos pacotes fixados no lockfile:
fontes Cinzel, Crimson Pro e Inter (`@fontsource`, 5.3.0), ícones Lucide (1.57.0)
e os avisos do Vite (8.3.4). Esses componentes conservam suas próprias licenças.
As fontes e os ícones são servidos pelo aplicativo, sem serviços externos.

PDF.js 6.4.299 e seus avisos ficam em `../vendor/pdfjs/`. Os dois livros conservam
os créditos e avisos dentro dos próprios PDFs; consulte também `../books/README.md`.
A licença MIT na raiz cobre o código próprio do projeto.
